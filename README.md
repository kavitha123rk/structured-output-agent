# Structured Output Agent 🤖

An AI-powered application that extracts structured
student information from unstructured text.

## Features
- Extract multiple student records
- Extract 8 fields per student
- AI-powered information extraction
- Structured JSON output
- Interactive Streamlit interface
- Data validation

## Technologies Used
- Python
- Ollama
- Qwen
- Streamlit
- Pydantic

## Installation

1. Clone the repository:

   git clone https://github.com/kavitha123rk/structured-output-agent.git

2. Install dependencies:

   pip install -r requirements.txt

3. Start the application:

   streamlit run app.py
